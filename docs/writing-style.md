# 書き方の決まり —— AI が書いた感じを抜く

**2026-09-20、Jev の記事の下書きに対して本人からもらった指摘の記録。**
次に記事を書くときは、書き始める前にここを読む。

> 下書きは「事実としては正しいが、人が書いたようには読めない」状態だった。
> 何がそう見せていたのかを、具体例つきで残す。

---

## 1. 論述っぽさが強い

### 指摘

> メリットデメリットの評価に終始し、感想が含まれないため無機質な AI らしさを感じる

### どう直すか

**口語体で書く。** やわらかさの基準は [/about](https://poina.petit-bouquet.com/about) と同じくらい。

```
質問にこたえていくと、その答えをまとめて AI に渡します。
AI は「16タイプのうち、どれにどれくらい近いか」を考えて、
いちばん近いものを教えてくれます。
```

- **です・ます**で書く
- **1文を短く**
- 「〜してくれます」「〜みたくて作りました」のような、人の動きが見える言い方にする

### ★ 感想を入れる ★

**評価だけ並べても、書いた人がどう思ったのかが伝わらない。**

| 評価だけ（AI っぽい） | 感想が入っている |
| --- | --- |
| 応答は 290〜320ms で、十分に高速である | 300ms で返ってくるので、待っている感じがしません |
| コストは 1 回あたり約 0.02 円と低廉 | 1 回 0.02 円。びっくりするくらい安いです |
| 形式エラーが発生しない点が利点 | パースに失敗しないのが、思っていたよりずっと楽でした |

**「うれしかった」「助かった」「正直まいった」を書く。** そこがいちばん人の文に見える。

## 2. 長い

### 指摘

> 詳細で確実な説明を望む読者は少ないです。

**下書きは本文だけで 15,600 字あった。** 書ける材料が多いと全部入れたくなるが、読む側にはつらい。

### ★ 最初に要点を 3 行 ★

**タイトルのすぐ下に、3 行で「何の話か」を置く。** ここだけ読んで離脱されてもいい、という気持ちで書く。

### 伝えたいことを先に決めて、そこから外れたものは落とす

**「書けること」ではなく「伝えたいこと」から始める。**
Jev の記事のときに決めたのはこの 7 つ。

1. Cloudflare で Jev を実際に運用した
2. 16 タイプ診断は、質問に対して 16 択の判断をする題材としてちょうどよかった
3. 1 診断ぶんのトークンでほぼ費用がかからない
4. Claude Code で半日で動くものができた
5. 曖昧な要求に答える条件分岐として使えそう
6. **精度は未検証。受けてみて合っていたか X で教えてほしい**
7. リーガル面のケア

> ★ **章を足したくなったら、この一覧のどれに当たるかを言えるか確かめる。** ★
> 言えないなら入れない。

### 表とコードを並べすぎない

下書きは**表が 10 個、コードブロックが 14 個**あった。
**資料としては親切でも、記事としては重い。** 1 つの章に 1 つまでを目安にする。

## 3. AI っぽい言葉を使わない

### 指摘

> AI 特有の、断言ワードや、英語直訳ワード（静かに、直ちに、正本、効く、投げきる、だいたい）は
> 別の言い換えをしてほしい

### ★ 言い換え表 ★

**名指しでもらったもの:**

| 使わない | 言い換え |
| --- | --- |
| 静かに（〜する） | そっと / 黙って / とくに何も言わずに |
| 直ちに | すぐに |
| 正本 | 元の場所 / ここが本物 / ここを直せばいい |
| 効く | 役に立つ / ここがうれしい / ここで差が出る |
| 投げきる | 1 回で送れる / まとめて渡せる |
| だいたい | たいてい / ほとんど / ざっくり |

**下書きで自分が使っていて、直したもの:**

| 使わない | なぜ | 言い換え |
| --- | --- | --- |
| 〜が要点だ / 〜が本題 | **記事の構造を説明している**だけ。読者には関係ない | 本文で自然に始める |
| 裏を返すと | 翻訳調 | 逆に言うと / つまり |
| 地味に効く | 「効く」が入っている | 意外とつまずくところ |
| 〜に他ならない / 明らかに | 断言が強すぎる | 〜だと思います / 〜みたいです |
| 怖いのは〜だ | 大げさ | 困るのは〜です |
| 実質ゼロだが、無料ではない | ★ **対句で締めるクセ** ★ AI っぽさが出る | ほぼタダです。ただしタダではないです |
| 〜は高い（コストが） | 直訳 | 手間がかかる / しんどい |

### 対句とオチで締めない

**「Xだが、Yではない」「Aではなく、B」で段落を閉じるのをやめる。**
1 回なら締まるが、続くと**型にはめて書いている**ように見える。
