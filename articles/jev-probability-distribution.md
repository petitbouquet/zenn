## Jev って何？

2026年9月に TypeSafe AI が出した、**文章を書かない AI** です。

普通の LLM はテキストを返しますが、Jev は返しません。選択肢を渡すと、**そのどれにどれくらい近いか**を数字で返してくれます。それだけです。

```json
{
  "choice": "INFP",
  "confidence": 0.68,
  "probabilities": { "INFP": 0.70, "INFJ": 0.24, "INTP": 0.03, "...": 0 }
}
```

何がうれしいかというと、**パースに失敗しないところ**です。

LLM に JSON を返してもらうと、たまに ```` ```json ```` が付いてきたり、前置きが混ざったりします。あれの面倒を見なくていいのは、思っていたよりずっと楽でした。

## 16タイプ診断が、題材としてちょうどよかった

Jev は「if 文と LLM のあいだを埋める道具」と説明されています。逆に言うと、**やりたいことが「分類」の形になっていないと、うまみが出ません。**

16タイプの性格診断は、そこにぴったりはまりました。

- 選ぶ先が **16個で固定**
- ほしいのは「どれか1つ」じゃなく **「どれにどれくらい近いか」**
- Jev の `choice` は選択肢を 255 個まで取れるので、16個なら 1 回でまとめて渡せます

渡すものはこれだけです。

```ts
await env.AI.run('typesafe/jev', {
  state: {
    回答: [
      { 設問: '知らない人が多い集まりでも、わりと平気で話しかけにいく。', 目盛り: 20 },
      // …
    ],
  },
  questions: {
    type: {
      type: 'choice',
      instructions: 'この回答をした人は、16タイプのうちどれにいちばん近いか。',
      criteria: { INTJ: 'ひとりの時間で元気が戻り…', INTP: '…' }, // 16個
    },
  },
})
```

### 画面を作る前に、確率の出かたを見ておきました

「2番目・3番目も出したい」という要件があったのですが、**1位に全部持っていかれる出かたしかしないなら、この要件はそもそも成り立ちません。**

画面を全部作ったあとで気づくと痛いので、先にダミーの回答を投げて確かめました。

| 投げたもの | 1位 | 2位 | 3位 |
| --- | --- | --- | --- |
| はっきり INTJ に寄せた | INTJ 96% | ISTJ 2% | INTP 2% |
| ゆるく INFP に寄せた | INFP 73% | INFJ 18% | INTP 6% |
| 全部まんなか | INTP 51% | ISTJ 19% | INTJ 7% |

はっきり寄せれば尖るし、ゆるく寄せれば散ってくれました。人が実際にやりそうな「ゆるく寄った」回答で 2位 18% なら、参考として出す意味があります。

これを見てから画面を作り始めました。**先に見ておいてよかったです。**

## 1 回 0.02 円は、さすがに神

実測です。

| | |
| --- | --- |
| 入力トークン | おためし（10問）で **約 3,000** |
| 出力トークン | **課金されません**（文章を返さないので） |
| 料金 | 1 回あたり **0.02 円に届きません** |
| 応答 | **300ms くらい**（初回だけ 1.2 秒） |

16タイプぶんの説明文を毎回まるごと渡しているので入力は数千トークンいくのですが、それでもこの値段です。

個人が遊びで作るものだと、**費用を気にしなくていいのが本当にありがたい**です。LLM で同じことをやろうとすると、ここが最初の悩みどころになります。

:::message
`wrangler dev` で手元から呼んでも本物の API を叩くので、開発中も少しずつ課金されます。とはいえ何百回試しても数円です。
:::

## Claude Code と半日でした

要件を渡してから本番が動くまで、実質半日くらいでした。

やってもらったのは、16タイプの説明文と設問30問の書き起こし、Hono のルーティング、確率の受け渡し、OGP 画像を焼くスクリプト、デプロイ前のチェック、あたりです。

一番ありがたかったのは、**作る前の調べもの**でした。次の「名前を決める前に」の章がそれです。あれを自分で全部やっていたら、半日では終わっていません。

いい時代になったなと思います。

## 引っかかったところ

1つだけ共有しておきます。**最初、5回続けて 502 になりました。**

```
X [ERROR] judge failed: 判定モデルが確率を返さなかった
[wrangler:info] POST /api/judge 502 Bad Gateway (285ms)
```

生のレスポンスを見て分かったのですが、**Workers AI から呼ぶと、返ってくるものが `result` で包まれます。**

```json
{
  "state": "Completed",
  "result": { "answers": { "type": { "choice": "ENTJ", "probabilities": { } } } }
}
```

TypeSafe の API を直接叩くと包まれないので、サンプルのまま `res.answers` を読みにいくと `undefined` になります。

まいったのは、**モデルのほうは 285ms でちゃんと答えていた**ことです。返事は正しいのに、こちらが読めていないだけ。「変な答えが返ってきているのかな」と思って調べにいくと遠回りします。

両方の形を読めるようにして解決しました。

```ts
const res = (raw?.result ?? raw) as { answers?: { type?: JevChoiceAnswer } }
```

## 名前を決める前に、商標を調べました

ここは技術の話ではないのですが、同じような題材で作る人には役に立つかもしれません。

:::message alert
以下は法律の専門家による助言ではありません。**個人サイトを公開する範囲で、自分で一度見にいった記録**です。商売にするなら弁理士さんに相談してください。
:::

調べたのは3つです。

**1つめ。** あの4文字の代名詞になっている名前は、日本で**第41類（教育・娯楽）を含めて商標登録されています**（登録第5292740号）。Web の性格診断はまさにこの区分なので、名乗るのはやめました。

危なかったのは、**リポジトリ名にその文字を入れかけていた**ことです。リポジトリを作る直前に気づきました。

**2つめ。** 「16タイプ」という言い方そのものは使えます。ただし J-PlatPat で引いたら、登録されているのは「16タイプ・パーソナルカラー」「16タイプ恋愛診断」のような、**「16タイプ＋用途」の組み合わせ**ばかりでした。なのでサービス名は自分で考えて、「16タイプ」は説明の中だけで使うことにしました。

**3つめ。** ここが一番意外だったのですが、**そのまま使えるタイプの説明文が、ひとつもありませんでした。**

- 有名な無料診断サイトの説明文 → 利用規約で複製と翻訳が禁止
- そのサイトの日本語の愛称 → **愛称そのものが翻訳の成果物**
- ユングの原文 → **没後70年なので 2031 年末まで保護されています**

というわけで、**16タイプの愛称も説明文も設問30問も、全部自分たちで書きました。**

![性格タイプ一覧。自作の愛称と説明文が並んでいる](/images/poina-types.png)
*「先を描くひと」「なぜを掘るひと」みたいな名前も、ぜんぶ考えました*

書いたあとに気づいたのですが、**これが結果的によかった**です。Jev に渡す判定の手がかり（`criteria`）は、要するに「そのタイプはどういう人か」を書いたもの。つまり**サイトに出す説明文と、モデルに渡すものがほぼ同じ**になりました。

説明文を練る作業が、そのまま精度を詰める作業になっていたわけです。よそから引いてきていたら、こうはなっていません。

## ★ 精度は、まだ確かめていません ★

正直に書くと、**当たっているかどうかは検証していません。**

そもそも性格診断に正解はないですし、Jev が返す確率がどれくらい妥当なのかも、分布の形を見ただけで「使えそう」と判断しただけです。

なので、**受けてみて感想をもらえるとうれしいです。**

https://poina.petit-bouquet.com

合っていたか、ぜんぜん違ったか、X で教えてください。ハッシュタグは `#16タイプっぽいな` です。

## おわりに

使ってみて一番そう思ったのは、**「曖昧な条件分岐」として置ける場所がけっこうありそう**だな、ということです。

if 文では書けないけれど、LLM に文章を書かせるほどでもない。そういう判断って、実は普段のコードにたくさん埋まっています。問い合わせの振り分けとか、入力のざっくりした分類とか。あそこに置けるものが出てきた感じがします。

速くて、安くて、形が崩れない。**しばらく使ってみます。**
